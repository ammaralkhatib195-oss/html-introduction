# HTML Introduction

A simple webpage built with HTML and CSS to practice basic web development.

## Overview

This project displays an HTML5 logo and a short description of HTML.

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `index.html` - Contains the webpage structure.
- `style.css` - Contains the styling rules.
- `html-logo.jpg` - The HTML5 logo image displayed on the page.

## Purpose

This project was created to practice the fundamentals of HTML and CSS.
